What I Learned Setting Up This Site

I set up this site to have a real, independent domain to practice SEO and AEO tools on, rather than relying only on theory. A few things stood out early on.

GitHub Pages requires an exact repo name match

The repository has to be named exactly as your username followed by .github.io, or GitHub won't treat it as a personal Pages site at all.

Pages settings live inside Settings, not the top nav

It's easy to miss — the Pages configuration is nested under "Code and automation" in the repository Settings tab, not visible as its own top-level tab.

Next steps

Now that the site is live, the plan is to run it through Ahrefs Site Audit and Site Explorer to start learning how technical SEO issues get flagged and fixed in practice.
